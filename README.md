# xAPI AI Agent Actions Profile (AIAAP)

An xAPI profile for recording what AI agents do, and, since 0.10.0, what robots, hybrid AI systems and swarms do.

- `ai_agent_actions_profile.json`: the profile (xAPI Profiles 1.0), generated by `tools/build_profile.py`. Edit the script, not the JSON.
- `ai_xapi_profile_concept.md`: the 0.9.0 design (software agents, MCP).
- `ROBOTICS_MODULE.md`: the 0.10.0 robotics and physical-AI module and its record-to-statement mapping.
- `GAPS.md`: where the I2IDL Glossary of Digital Learning has no matching concept yet.
- `examples/`: example statements.

Base IRI `https://w3id.org/xapi/ai/` (registration with w3id.org pending).
