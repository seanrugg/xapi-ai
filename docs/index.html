xAPI AI Agent Actions Profile (AIAAP)

Version 0.10.0. Profile IRI https://w3id.org/xapi/ai/profile. Profile document (JSON-LD) · Source · Robotics module and mapping · Glossary gaps

Captures human instructions and AI agent operations, including MCP tool calls, resource access, generation, delegation, evaluation, approvals and governance outcomes. Version 0.10.0 adds a robotics and physical-AI module for robots, hybrid AI and swarms: one verb per memory-record type, telemetry windows (pose, navigation, sensor), and provenance extensions that let any statement be verified against its signed source record. Concepts are aligned with the I2IDL Glossary of Digital Learning (v0.0.93) where a match exists.
